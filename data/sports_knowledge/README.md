# XSportsX Sports Knowledge Brain

This directory is the static domain layer for the Sports Agent.

## What belongs here

- `sports.json`: sport mechanics and aliases.
- `leagues.json`: league identity, season model, and event granularity.
- `event_types.json`: games, fights, shows, race sessions, and rounds.
- `lifecycle_rules.json`: sport-aware pregame/live/expiry inference.
- `broadcast_patterns.json`: session-aware broadcast and source behavior.
- `terminology.json`: status/session language normalization.
- `learned_lessons.json`: validated operational corrections generated by the agent.

## Trust model

Static knowledge is domain guidance, not canonical event truth. Official league/event evidence and verified provider state outrank the knowledge files. Learned lessons must be evidence-backed before they can affect decisions.

The brain must never invent a game, start time, live state, channel, or source.
